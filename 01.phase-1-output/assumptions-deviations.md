# Assumptions and deviations register

## Governing constraint

The artifacts are source-derived from five COBOL files and are **not** a claim of full CardDemo, record compatibility, pixel fidelity, or behavioral equivalence. Any status below other than Confirmed is not a recovered legacy requirement.

| ID | Area | Legacy evidence | Decision / assumption / deviation | Status | Validation / exit condition |
|---|---|---|---|---|---|
| A-01 | Release boundary | Five programs cover sign-on/admin/user CRUD; non-admin routes to absent `COMEN01C` (`COSGN00C.cbl:230-239`). | Release only identity and user administration; exclude regular-menu, card, account, transaction and other unknown modules. | Confirmed scope cap | Expand only after source/contracts are recovered. |
| A-02 | User schema | Five `SEC-USR-*` fields are used but `CSUSR01Y` is absent (`COUSR01C.cbl:153-160`). | Model a provisional User with ID, first name, last name, password hash, role, version. The current initial Flyway migration applies modern constraints (`user_id` 64, names 128, role 16) but they are not claims about legacy physical sizes/order. | Inferred | Recover `CSUSR01Y`, USRSEC catalog/key/encoding, map copybooks; reassess/reconcile the provisional constraints before legacy import or fidelity claim. |
| A-03 | User-ID casing | Sign-on uppercases ID (`COSGN00C.cbl:132-134`); CRUD does not visibly uppercase IDs. | Normalize IDs to uppercase across modern API to keep a single identity key. | Inferred, source-compatible for sign-on | Confirm CRUD map/data semantics and migration data. |

## Required recovery package before fidelity claims

1. Project copybooks: `COCOM01Y`, `COADM02Y`, `COSGN00`, `COADM01`, `COUSR01`, `COUSR02`, `COUSR03`, `COTTL01Y`, `CSDAT01Y`, `CSMSG01Y`, `CSUSR01Y`.
2. BMS map source/generation inputs for all five named mapsets.
3. `USRSEC` record/data definition, key/organization, encoding, and scrubbed resettable fixtures.
4. `COMEN01C`, configured admin targets, CICS resource definitions, build/link inputs, runtime instructions, and an executable oracle.

Without these, keep scope at five-program workflow documentation and do not claim more.
